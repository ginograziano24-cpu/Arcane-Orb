# Character references (for the Blender models)

Drawn in the intro's flat cartoon style; front, side and back of each sheet share the same
height guides, so they can be set up as orthographic image planes in Blender.

- `mirabel_turnaround.png`: Mirabel, key pose (hand on hip, staff), 8 heads. Low wavy ponytail.
  Guides: crown, chin, shoulders, bust, waist, hips, knee, floor.
- `mirabel_face_v2.png`: face close-up (light makeup, dark brown eyes, lower brows).
- `mirabel_ponytails.png`: ponytail options (back view); the user picked the low wavy one.
- `mirabel_hairstyles.png`: earlier loose hairstyles (not used).
- `fumbleton_turnaround.png`, `fumbleton_detailed.png`: Archmage Fumbleton.
