# Arcane Orb: opening cinematic (draft 1)

Plays before the first run, about 49 seconds. Skippable, plays once on first
launch, rewatchable from the Codex. The first half is pencil sketches on
notebook paper; when the Orb falls onto the page it burns through it, and
the rest is dark violet arcane magic (rune circles, glowing gold).
Preview: the "Arcane Orb Opening" artifact.
